🛠️ 1. วิธีส่งออกไฟล์ .bin จากโปรแกรม Arduino IDE

▼
  • 1
    เปิดโปรแกรม Arduino IDE แล้วเปิด Sketch โค้ดที่ต้องการ
  • 2
    เลือกบอร์ด ESP32 ที่ถูกต้อง เช่น ESP32 Dev Module หรือบอร์ด Espino32
  • 3
    ไปที่เมนูด้านบน Sketch > คลิก Export Compiled Binary (หรือกดคีย์ลัด Ctrl + Alt + S บน Windows / Cmd + Alt + S บน Mac)
  • 4
    รอจน Compile เสร็จ จากนั้นคลิกเมนู Sketch > Show Sketch Folder จะพบไฟล์ที่มีนามสกุล .ino.bin (เช่น my_code.ino.bin)
  • 5
    นำไฟล์ .bin ดังกล่าวมาลากวางในแท็บ "อัปโหลดไฟล์ .bin จากเครื่อง" บนเว็บนี้ได้ทันที!

🔌 2. คำแนะนำสำหรับบอร์ด Espino32 (ThaiEasyElec) และไดรเวอร์

▼

บอร์ด Espino32 ของ ThaiEasyElec ใช้ชิปแปลงสัญญาณ USB-to-UART ตระกูล Silicon Labs CP2104 / CP2102:

  • •
    หากเสียบสายแล้วไม่พบพอร์ต Serial: คอมพิวเตอร์อาจยังไม่มีไดรเวอร์ CP210x ให้ดาวน์โหลดและติดตั้งได้ฟรีที่ Silicon Labs CP210x VCP Drivers
  • •
    สาย USB: ต้องเป็นสาย Data ที่ส่งข้อมูลได้ (สายชาร์จทั่วไปบางเส้นมีเฉพาะสายไฟเลี้ยง + / - ทำให้มองไม่เห็นพอร์ต)

🚨 3. วิธีแก้ปัญหาเมื่อกด Connect แล้วขึ้น "Failed to connect" หรือ Time out

▼
💡 ทริคสำคัญ: หากบอร์ดไม่ยอมเข้า Bootloader Mode อัตโนมัติ ให้ทำตามขั้นตอนนี้
  • 1
    มองหาปุ่ม BOOT หรือปุ่ม IO0 บนบอร์ด Espino32
  • 2
    กดปุ่ม BOOT ค้างไว้
  • 3
    คลิกปุ่ม Connect & Flash บนหน้าเว็บและเลือกพอร์ต COM
  • 4
    เมื่อหน้าต่างขึ้นข้อความว่ากำลังเชื่อมต่อ (Connecting...) ให้ปล่อยปุ่ม BOOT ระบบจะเริ่มดาวน์โหลดโปรแกรมลงชิปทันที

🧠 4. ทำไมต้องเลือก Offset 0x10000 หรือ 0x0 ?

▼

ชิป ESP32 แบ่งโครงสร้างหน่วยความจำ Flash เป็นส่วนต่างๆ:

  • 📍
    Offset 0x10000 (หรือ 65536): เป็นตำแหน่งเก็บโค้ดหลัก (Application) เมื่อเรา Export จาก Arduino IDE ตัวไฟล์ .ino.bin จะมีเฉพาะส่วนนี้ จึงต้องเขียนที่ตำแหน่ง 0x10000 เพื่อไม่ให้ไปลบ Bootloader (0x1000) และ Partition Table (0x8000) ของเดิม
  • 📦
    Offset 0x0 (หรือ 0): ใช้เฉพาะไฟล์แบบ merged.bin ซึ่งเป็นไฟล์ที่รวม Bootloader + Partitions + โค้ดโปรแกรมเข้าเป็นก้อนเดียวตั้งแต่ต้นทาง
